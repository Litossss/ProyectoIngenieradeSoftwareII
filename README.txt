# Repuestos Anelisa

## Proyecto

Aplicación de escritorio para el control de inventario del almacén **Repuestos Anelisa**.

## Materia

**Ingeniería de Software II**

## Integrantes

- Jesús Eduardo González Figueredo
- Reinaldo Andrés Girón Castro
- Sebastián Pérez Pacheco

## Descripción

El proyecto consiste en el desarrollo de una aplicación de escritorio orientada a la gestión del inventario del almacén Repuestos Anelisa.

El sistema permitirá administrar productos, registrar compras y ventas, consultar existencias, gestionar usuarios y generar reportes relacionados con la operación del almacén.
